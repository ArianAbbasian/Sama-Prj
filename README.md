# سامانه مدیریت بیماران

یک اپلیکیشن مدیریت بیماران توسعه داده شده با Next.js، Material-UI و Tailwind CSS

## ویژگی‌ها

- ✅ احراز هویت با JWT
- ✅ مدیریت کامل بیماران (CRUD)
- ✅ طراحی RTL و فارسی
- ✅ رابط کاربری مدرن با Material Design
- ✅ مدیریت وضعیت با Redux Toolkit
- ✅ واکنش‌گرا (Responsive)
- ✅ محافظت از Routeها

## تکنولوژی‌ها

- Next.js 15
- React 19
- Material-UI (MUI)
- Tailwind CSS
- Redux Toolkit
- Axios
